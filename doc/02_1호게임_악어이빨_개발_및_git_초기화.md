### 3) 1호 악어 이빨 게임 시각/청각/촉각 고도화
1. **실감나는 모바일 악어 그래픽 적용**:
   - 기존 단순 텍스트/이모지 그리드에서 벗어나 악어의 **초록색 윗턱(상악), 눈동자(두리번 애니메이션), 콧구멍, 붉은 입안, 아랫턱(하악)** 구현.
   - 입체적인 3D 화이트 이빨 버튼 적용 (터치 시 쏙 들어가는 효과).
2. **Web Audio API 기반 0초 로딩 사운드 시스템 ([public/js/audio.js](file:///d:/My%20Web%20App/2026-MiniGame/public/js/audio.js))**:
   - 외부 mp3 다운로드나 CDN 의존 없이 브라우저 내장 오디오 합성기로 즉각 소리 생성.
   - 이빨 터치음 (`playClick`), 안전 생존음 (`playSafe`), 꽝 물림 충격음 (`playChomp`), 턴 알림음 (`playTurn`) 탑재.
   - 사운드 On/Off 토글 버튼 제공.
3. **스마트폰 진동(Haptics) & 연출 효과**:
   - 턴 도착 시 미세 진동(25ms), 이빨 터치 시 햅틱(30ms).
   - 꽝 이빨 터치 시: **화면 전체 스크린 셰이크(Shake) + 악어 윗턱이 쾅 닫히는 CHOMP 애니메이션 + 묵직한 물림 사운드 + 강력한 진동 패턴 (`[80, 50, 80, 50, 300]`)**.
   - 1.2초간 긴장감 있는 물림 연출 후 최종 결과 화면으로 부드럽게 전환.
4. **결과 공유 & 단톡방 연동**:
   - `Web Share API` 및 클립보드 복사를 통한 카카오톡 단톡방 결과 1초 공유.
   - 벌칙 항목(`inputPenalty`)과 패배자 이름 표시.
   - "대기실로 돌아가 한 판 더!" 버튼으로 원클릭 재경기 지원.

## 3. 로컬 서버 실행 및 접속 방법

터미널에서 아래 명령어로 서버를 구동할 수 있습니다:
```bash
npm start
# 또는 개발 모드 (자동 재시작)
npm run dev
```

- **PC 브라우저 접속**: `http://localhost:3000`
- **스마트폰 접속**: 동일 Wi-Fi 환경에서 PC의 로컬 IP(예: `http://192.168.x.x:3000`)로 접속하거나 초대 링크를 복사하여 테스트 가능합니다.
