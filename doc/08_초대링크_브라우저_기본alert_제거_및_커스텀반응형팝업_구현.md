> **프로젝트**: `2026-MiniGame`  
> **관련 파일**: [public/index.html](file:///d:/My%20Web%20App/2026-MiniGame/public/index.html), [public/js/app.js](file:///d:/My%20Web%20App/2026-MiniGame/public/js/app.js)

## 1. 개선 배경 및 사용자 요구사항
* **문제점**:
  * 기존 [링크 복사] 클릭 시 브라우저 기본 창(`alert()`)이 뜨면서 상단에 `localhost:3000 내용`과 같은 보기 흉하고 구식인 다이얼로그가 표시됨.
* **사용자 요구사항**:
  1. `localhost:3000 내용` 기본 alert 창 완전 제거.
  2. 불필요한 *"초대 링크가 복사되었습니다"* 문구 제거.
  3. **초대 링크 주소**와 *"다른 창이나 친구들에게 공유하세요."* 안내 문구 유지.
  4. **PC/모바일 반응형 커스텀 팝업창(모달)**으로 세련되게 표시.

---

## 2. 적용된 구현 상세

### 1) PC/모바일 최적화 커스텀 모달 UI ([index.html](file:///d:/My%20Web%20App/2026-MiniGame/public/index.html))
* **백드롭 블러 효과**: `backdrop-blur-sm bg-slate-950/80`으로 배경을 어둡고 고급스럽게 처리.
* **반응형 컨테이너**: 모바일 화면(최대 너비 380px)과 데스크톱 화면 어디서나 자연스럽게 중앙 배치되는 카드 디자인.
* **인라인 링크 박스 & 원클릭 복사**:
  * 앰버 컬러의 모노스페이스 폰트로 링크 주소를 보여주는 인풋창(`select-all`).
  * 인풋 우측에 `[복사]` 액션 버튼 배치 (클릭 시 `✅ 복사됨!` 피드백 전환).
* **안내 문구**: *"다른 창이나 친구들에게 공유하세요."*
* **다양한 닫기 인터랙션**:
  * 상단 우측 `✕` 버튼
  * 하단 `[확인]` 버튼
  * 모달 바깥 배경 터치/클릭 시 닫기

### 2) 클라이언트 이벤트 제어 ([app.js](file:///d:/My%20Web%20App/2026-MiniGame/public/js/app.js))
* [링크 복사] 클릭 시:
  * 브라우저 기본 `alert`는 일절 호출하지 않음.
  * `navigator.clipboard.writeText()`로 클립보드에 무음 자동 복사를 선행 시도.
  * 커스텀 모달(`modalInvite`)을 띄우고 링크를 자동 선택(Focus/Select).
* 모달 내부의 [복사] 버튼을 누르면 다시 클립보드에 복사되고 녹색 `✅ 복사됨!`으로 시각 피드백 제공.
