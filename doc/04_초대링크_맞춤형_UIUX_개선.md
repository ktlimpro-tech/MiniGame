## 1. 개선 배경 및 사용자 피드백
* **사용자 피드백**:
  > *"초대 링크 클릭했을 때, '새 게임 방 만들기'는 비활성화하고, 참여하기만 활성화되어야 하는 것 아닌가? 초대받은 자가 새로운 방을 만드는 건 좀 아니지 않나?"*
* **UX 분석**:
  * 100% 맞는 지적입니다. 친구의 초대 링크(`?room=XXXX`)를 눌러 들어온 사람의 단 하나의 목적은 **"그 방에 닉네임 치고 바로 들어가는 것"**입니다.
  * 기존에는 가장 눈에 띄는 노란색 큰 버튼이 "✨ 새 게임 방 만들기"여서 참가자가 실수로 누를 위험이 컸습니다.

---

## 2. 적용된 UX 개선 내용

### 1) 초대 모드(`Invite Mode`) 자동 감지 및 맞춤 화면 전환
* URL에 `?room=CODE` 파라미터가 있을 경우:
  1. **초대 안내 배너 표시**:
     * `📩 친구의 게임 방에 초대되었습니다!`
     * `초대 방 코드: [XXXX]`
  2. **"새 게임 방 만들기" 버튼 및 방 코드 수동 입력창 완전 숨김 (`hidden`)**
  3. **대형 메인 액션 버튼 제공**:
     * `[🚀 바로 게임 참여하기]` 전폭 녹색 버튼 노출!
     * 닉네임만 입력하고 버튼을 누르면 1초 만에 바로 입장.

### 2) 닉네임 입력 편의 (Enter 키 지원)
* 닉네임 입력창에서 엔터(Enter) 키를 누르면:
  * 초대 모드일 때는 즉시 해당 초대 방으로 원클릭 입장 실행.
  * 일반 모드일 때는 입력된 상황에 맞춰 자동 입장.

### 3) 자유도 보장 (내가 새 방 만들기 옵션)
* 혹시라도 본인이 새 방을 파고 싶어진 사용자를 위해:
  * 하단에 작은 링크(`내가 새로운 게임 방 만들기`)를 제공하여 필요 시 일반 홈 화면으로 전환할 수 있게 했습니다.

---

## 3. 화면 동작 비교

| 구분 | 일반 접속 (`http://.../`) | 초대 링크 접속 (`http://...?room=3SHY`) |
| :--- | :--- | :--- |
| **메인 배너** | "누가 커피 살지 30초 만에 결정!" | "📩 친구의 게임 방에 초대되었습니다! (방: 3SHY)" |
| **새 방 만들기** | 노란색 대형 버튼 노출 | **완전 숨김/비활성화** |
| **입장 방식** | 방 코드 4자리 입력 + 참여하기 | **닉네임 입력 후 [🚀 바로 게임 참여하기] 원클릭** |
| **실수 방지** | 기본 모드 | 친구 방을 이탈하여 엉뚱한 방을 파는 실수 원천 차단 |
